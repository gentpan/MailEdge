# MailEdge v0.2.3

This release focuses on email rendering fidelity, mailbox data safety and a
repeatable release-quality test baseline.

## Highlights

- Email HTML now remains readable across application light and dark themes,
  including messages with native dark CSS, fixed dark backgrounds, images,
  links, tables and quoted content.
- Legacy Outlook-style fixed-width tables shrink safely in narrow split views
  and retain their authored width on wide screens.
- Sender avatars use the same domain-brand source in the list and detail header;
  the selected message loads its avatar eagerly to avoid a visible mismatch.
- Mailbox catch-all assignments are repaired deterministically and protected by
  a database invariant in migration `0007`.
- Message, mailbox and contact APIs received additional ownership and session
  boundary regression coverage.

## Verification

- Biome and all TypeScript projects pass.
- 273 Worker/Vitest tests and five disposable-SQLite migration tests pass.
- Chromium, Firefox and WebKit smoke/authentication checks pass (10 tests).
- The production Vite build succeeds and the dependency audit reports no
  high-or-higher vulnerabilities.
- Deterministic local fixtures cover 83 messages, six categories, light/dark
  email variants, Outlook tables, long content, RTL, read and starred states.

The destructive Cloudflare install, upgrade, uninstall and rollback matrix is
tracked separately in the
[v0.2.3 QA status report](https://github.com/gentpan/MailEdge/blob/v0.2.3/docs/QA-STATUS-2026-08-09.md)
and must only run against a disposable Cloudflare account, never production or
customer data.
