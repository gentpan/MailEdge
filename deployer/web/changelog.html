v0.1 · 初始版本 2026-07

  • 四渠道发信：Cloudflare / Resend / Sendflare / SMTP，主备自动切换
  • 收信：Email Routing → Worker，Durable Object + SQLite 分片存储
  • 新信 WebSocket 实时推送 + 60 秒轮询兜底
  • AI 助手：自动回复、总结、分类；Telegram 推送
  • 智能附件：大附件自动转 R2 下载链接
  • 界面中英双语、Markdown 写信
  • 质量基建：Vitest 测试、Biome 校验、一键部署脚本、CRLF 头注入防护
