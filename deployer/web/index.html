MailEdge 一键部署

在你的 Cloudflare 账户里自动创建数据库、存储与 Worker，部署完成得到专属邮箱系统。

1创建并粘贴 Cloudflare API Token

部署全程只使用你这次创建的 一次性 Token，部署完成后请删除它。 我们不会保存它，也看不到你的账号密码。

点击下方按钮打开 Cloudflare 后台，创建 Token 时需要勾选这些权限（按说明选）：

  • 账户 · Workers Scripts — Edit
  • 账户 · Workers R2 Storage — Edit
  • 账户 · Workers D1 — Edit
  • 账户 · Workers KV Storage — Edit
  • 账户 · Email Routing Addresses — Edit
  • 区域 · Email Routing Rules — Edit
  • 区域 · Zone — Read

创建完成后，把 Token 粘贴到下面：

2选择账户与收信域名

🎉 部署完成

你的 MailEdge 管理面板：

首次打开会进入初始化页，创建管理员账号并绑定收件地址。

请务必回到 Cloudflare 后台删除刚才的 Token，它已完成使命，删除后立即失效。
路径：Cloudflare 后台 → 我的个人资料 → API Tokens → 删除。
