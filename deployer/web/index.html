一键部署

在你的 Cloudflare 账户里自动创建数据库、存储与 Worker，部署完成得到专属邮箱系统。

创建并粘贴 Cloudflare API Token

部署全程只使用你这次创建的 一次性 Token，部署完成后请删除它。 我们不会保存它，也看不到你的账号密码。

打开 Cloudflare 后台创建 Token。推荐做法：
选 "Edit Cloudflare Workers" 模板 → 再点 "Add more permissions" 补上 D1 一项：

权限（中文）Cloudflare 后台英文名分类标签选
Workers D1 数据库D1AccountEdit

模板已含 Workers Scripts / R2 / KV 等权限，无需重复添加。
提示：点 "Add more permissions" 后顶部有 Account/Zone/User 三个标签，D1 在 Account 下。部署不需要域名与 Email 权限——收件地址部署完成后在 MailEdge 设置页自行添加。

创建完成后，把 Token 粘贴到下面：

选择账户并一键部署

部署只创建基础资源（Worker / D1 / R2）。收件地址在部署完成后，到 MailEdge 设置页自行添加管理，可添加多个。

卸载已部署的 MailEdge

注意：删除会永久清空该账户下的 MailEdge 数据（邮件、附件、数据库），不可恢复。请先在下方确认要删除的资源。

部署完成

你的 MailEdge 管理面板：

首次打开会进入初始化页，创建管理员账号。

想用自己的域名访问？
打开 Cloudflare 后台 → Workers 与 Pages → 你的 mailedge → 设置 → 域名 → 添加自定义域， 绑定你的域名（如 mail.你的域名.com），按提示添加 DNS 记录即可。
如何开始收信？
在 MailEdge 的「设置 → 收件地址」里添加你的邮箱地址（可添加多个）；然后到 Cloudflare 后台 Email Service → Email Routing，把域名收到的信（Catch-all 或具体地址）投递给 mailedge Worker。
请务必回到 Cloudflare 后台删除刚才的 Token，它已完成使命，删除后立即失效。
路径：Cloudflare 后台 → 我的个人资料 → API Tokens → 删除。
