隐私政策

MailEdge 是自托管项目——你的邮件数据存储在你自己的 Cloudflare 账户里，运营方不接触、不存储。

数据存储位置

数据存放位置
邮件正文你账户的 Cloudflare D1 / Durable Object（SQLite）
附件与原始报文你账户的 Cloudflare R2
账户、渠道配置、发信记录你账户的 Cloudflare D1

部署在你自己的 Cloudflare 账户下，数据完全属于你。卸载实例即可删除全部数据。

加密

  • 发信渠道密钥、AI Key、Telegram Token、更新 Token：AES-GCM 加密后存 D1
  • 账户口令：PBKDF2 哈希（含随机盐）
  • 登录会话：HttpOnly Cookie + 签名令牌

更新 Token

设置 → 更新里保存的更新 Token 同样加密存储；接口只返回「是否已配置」，绝不回传内容。可随时在设置页清除。

安装向导（mailedge.sh）

  • 部署/更新时你提供的一次性 API Token 仅在服务器内存中用于那一次请求，不落库、不写日志
  • 页面会提醒你部署完成后删除 Token

第三方服务

  • 收信：Cloudflare Email Routing 处理来信转发
  • 发信：Resend / Sendflare / SMTP 等发信服务商会接触你发送的邮件内容（这是发信行为本身的要求）
  • AI 助手（可选）：启用后，邮件内容会发送给你配置的 AI 服务商（OpenAI、DeepSeek 等）用于总结/分类/回复

Cookie

仅用于登录会话的 HttpOnly Cookie，无广告、无第三方追踪。

数据导出与删除

卸载实例（见使用说明第八节）会删除 Worker、数据库与存储中的邮件数据。邮件正文不设云端后台，删除即不可恢复。
